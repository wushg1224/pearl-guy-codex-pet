# 珍珠小子独立桌宠 App / Standalone Desktop Pet

不开 Codex 也能让珍珠小子待在桌面上：Swift/AppKit 原生 App，聊天窗口使用系统 WebKit，
直接读取本仓库的 `bead-girl/spritesheet.webp`（Codex pet 标准 8 列 × 9 行图集，
每格 192×208），按 Codex 官方的帧时长逐帧播放。

## 构建

```bash
cd desktop-app
./build.sh
```

默认仅构建到 `desktop-app/build/珍珠小子.app`。使用 `./build.sh --install` 会先备份桌面旧版，再安装新版。无 Dock 图标；右键宠物可退出。

## 行为

- 常驻 idle 待机动画（呼吸、眨眼）
- 每 20–50 秒随机小动作：散步（窗口真实移动）、挥手、跳跃、干活、等待、张望，偶尔沮丧
- **鼠标 hover** → 抱抱（需要扩展雪碧图第 10 行；没有时暂用挥手代替）
- 按住拖动可搬家；右键菜单：和小鱼聊天 / 打招呼 / 跳一跳 / 去散步 / 认真干活 / 换体型（小中大）/ 退出

## 认真干活：持续循环

右键选择 **「认真干活 💻」** 后持续播放电脑打字动画，直到再次右键点击桌宠才停止并回到待机，同时打开菜单。工作期间暂停随机动作；鼠标进出、左键点击和拖动不会中断。停止后可以再次从菜单开始。

## 独立聊天窗口（PRD 3）

右键珍珠小子，第一项选择「和小鱼聊天」。窗口默认内容尺寸 420 × 680，可输入、缩放，并记住位置和尺寸。重复点击会唤起同一个窗口，不重载正在进行的聊天。

- 调用 `ChatServiceManager.ensureReady` 自动准备服务，显示启动进度、失败原因和重试按钮。
- 默认项目目录为 `/Users/ceci/Documents/GitHub/idol-companion`；失效时可选择包含 `compose.yaml` 的目录，选择会保存。
- 使用 App 自己的持久化 WebKit 数据存储，不导入 Safari 或 Chrome 的旧记录。首次从空记录开始，之后保留自己的聊天、设置和草稿。
- 关闭窗口或退出桌宠时，等待 `window.pearlPetChat.prepareToClose()` 停止生成并保存；保存失败会保留窗口，点击「重试」会再次尝试关闭。
- 网页进程崩溃、关闭接口不可执行或 15 秒内无响应时，停止加载并释放网页；下次只能恢复此前已保存的内容。
- 关闭聊天窗口后桌宠继续运行；退出桌宠不会停止 Docker 或小鱼服务。
- 网页链接交给系统浏览器打开。

首次集成已于 2026-09-07 执行 `docker compose up -d --build`，并检查运行网页包含 PRD 2 关闭接口。以后小鱼代码更新时，需在其项目目录重新执行该命令。
